# 🕷️ Job Postings Web Scraper

A Python-based web scraping tool built with [Scrapy](https://scrapy.org/) to extract structured job posting data from [Meta Careers](https://www.metacareers.com/jobs).

## 🔍 Features
- Crawls job listing pages and follows individual job links to extract detailed descriptions.
- Captures key fields such as:
  - **Job Title**
  - **Responsibilities**
  - **Minimum and Preferred Qualifications**
- Uses CSS selectors for precise data extraction.
- Designed for easy extension to other job platforms or API integrations.

## ⚙️ Technologies Used
- Python  
- Scrapy  
- CSS Selectors
